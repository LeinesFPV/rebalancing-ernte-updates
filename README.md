# Rebalancing-Ernte – Updates

Hier liegen nur die fertigen Versionen der App Rebalancing-Ernte. Die App schaut einmal am Tag in `version.json` nach, ob es etwas Neues gibt.

**Aktuelle Version: 1.5** (2026-10-31)

[Ernte-1.5.apk herunterladen](https://github.com/LeinesFPV/rebalancing-ernte-updates/raw/main/Ernte-1.5.apk)

## Neu in dieser Version
- Neu: Signale – Kauf-Ideen von Claude mit Ziel, Stop-Loss und spätestem Verkaufsdatum
- Die App meldet sich, wenn du eine gekaufte Signal-Aktie verkaufen solltest
- Ehrliche Bilanz: Trefferquote aller Signale im Vergleich zum Welt-ETF

## Installieren
1. APK auf dem Handy herunterladen und öffnen.
2. Android einmal erlauben, Apps aus dieser Quelle zu installieren.
3. Über eine ältere Version installieren: Einstellungen, Stückzahlen und Anmeldung bleiben erhalten.

Ältere Versionen liegen im Ordner [alte-versionen](alte-versionen).
